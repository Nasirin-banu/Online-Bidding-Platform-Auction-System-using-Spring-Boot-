# Online-Bidding-Platform-Auction-System-using-Spring-Boot-
This project is a web-based online bidding platform developed using Spring Boot. It enables users to participate in auctions by placing bids on listed items. The application manages user interactions, bidding processes, cart operations, and order tracking through a structured backend system and a simple web interface.

# Features
User management functionality
Auction listing and bid placement
Cart and order management
Wallet handling system
Return management
Data handling using JSON files
Basic web interface for user interaction
Technology Stack
Java
Spring Boot
Maven
HTML, CSS, JavaScript
JSON (data storage)

# Project Structure
backend/
│── src/main/java/        Application source code
│── src/main/resources/   Configuration and static files
│── data/                 JSON data storage
│── pom.xml               Project dependencies
Installation and Setup

# Clone the repository
git clone https://github.com/your-username/online-bidding-platform.git

# Navigate to the project directory
cd online-bidding-platform
# Run the application
mvn spring-boot:run
# Access the application
Open a browser and go to:
http://localhost:8080
 
# Usage
Users can browse available auction items, place bids, and manage their orders through the application interface. The system processes user actions and maintains data using JSON-based storage.
